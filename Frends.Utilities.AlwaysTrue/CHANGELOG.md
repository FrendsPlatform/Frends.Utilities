# Changelog

## [2.0.0] - 2026-11-03
### Changed
- The Task now accepts default `Input` and `Options` parameters.
- **[Breaking Change]** The result now contains `Success` and `Error` properties instead of `TaskResult`.
- The Task now targets .NET 8.
- Added `ThrowErrorOnFailure` and `ErrorMessageOnFailure` options for error handling.
